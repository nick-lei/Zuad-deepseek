# Zuad 信发助手

通过对话制作节目、管理素材、安排播放并操作设备，让广告屏、门店屏和大厅信息屏的日常管理更方便。

## 可以做什么

| 日常工作 | 可以交给助手的操作 |
| --- | --- |
| 节目制作 | 新建、复制和修改节目，使用已有模板，调整文字、图片、位置、尺寸与播放时长 |
| 多种布局 | 制作九宫格、全屏轮播、左右图文、分屏组合、横竖屏和多内页节目 |
| 素材管理 | 查询、上传和整理素材，将图片、视频、音频与文档加入节目 |
| 播放安排 | 下发节目或节目组，设置默认播放，创建定时排程和临时插播，检查时间冲突 |
| 设备管理 | 查找设备及分组，获取设备信息、请求截图、重启设备，查看任务执行结果 |
| 运营查询 | 按条件查找节目、任务、播放记录和操作日志，查询系统已开放的统计数据 |

节目可以组合图片、视频、文字、走马灯、时钟、二维码、表格和网页等内容。PC 与会议类控件的实际效果取决于播放器和业务服务是否支持。

## 使用优势

- **用日常语言安排工作**：说清内容、布局、目标屏幕和时间，无需自己填写接口参数或布局数据。
- **减少重复操作**：从已有节目或模板开始，批量替换内容、调整播放安排，适合经常更新的门店活动和通知。
- **节目仍可继续编辑**：保存到信发系统后，可以在原后台打开节目，继续调整控件、素材和时间轴。
- **素材与节目关联完整**：上传素材时登记素材库，保存节目时同步素材列表与播放信息；表格内容修改后重新生成播放图片。
- **适用于云端后台**：配置系统地址即可连接已有信发系统，无需准备本地编辑器、浏览器路径或后台项目源码。

## 开始使用

在 DeepSeek Harness 的“插件 → 添加插件”中填写下面的地址，安装后选择“立即启用”：

```text
github:nick-lei/Zuad-deepseek#v0.1.0
```

也可以在 [版本发布页](https://github.com/nick-lei/Zuad-deepseek/releases) 下载 `.tgz` 安装包，或将该附件的下载链接填入“添加插件”。支持 DSH `0.2.1-rc.5` 与 `0.2.2-alpha.2`；其他版本需要另行验证。

1. 在插件详情页启用“Zuad 信发助手”。
2. 填写后台地址、组织编号、操作用户 UID 和操作人名称，点击“保存配置”。这些信息可向系统管理员获取。
3. 在对话中说明你要完成的工作。第一次使用可以先说：“检查信发系统是否连接正常，并列出我已有的节目。”
4. 制作节目时，提供要使用的素材或素材名称，说明屏幕方向、布局、文字内容和播放时长。保存后可到后台查看，再安排下发。

认证由已接入的系统配置提供，详情页无需填写 API Key。高级设置通常保持默认即可。

新环境需要管理员预先接入后台授权，安装插件不会自动取得后台访问权限。部署与构建说明见 [开发与部署](docs/development.md)。

## 可以这样说

### 制作九宫格

> 用素材库里的“春季上新”系列图片做一个横屏九宫格节目，尺寸为 1920×1080，按图片名称顺序排列，保存为“春季上新九宫格”，先不要下发。

### 制作图片轮播

> 把我提供的 6 张活动海报上传到素材库，制作一个全屏轮播节目，每张显示 5 秒，保存为“门店活动轮播”。

### 制作图文节目

> 创建一个竖屏节目，上方显示“本周精选”，中间轮播素材库里的新品图片，下方显示“活动时间：11 月 1 日至 11 月 7 日”。保存后给我看预览。

### 修改已有节目

> 找到“一楼大厅欢迎屏”，把标题改成“欢迎参加新品发布会”，替换为我提供的背景图片，另存为“发布会欢迎屏”。

### 安排播放

> 先查找“大堂屏幕组”和“发布会欢迎屏”，列出对应的设备和节目，供我确认下发目标。

> 给“门店活动轮播”创建明天 9:00 到 18:00 的播放排程，目标是“一楼大厅屏”，先检查是否与已有排程冲突。

### 检查执行结果

> 查询刚才的下发任务，告诉我哪些设备已经成功、哪些还在等待，以及哪些执行失败。

## 使用时了解这些

- **保存和下发是两件事**：只想先制作内容时，可以明确说“保存，先不要下发”。
- **下发需要等待设备执行**：任务创建成功不代表屏幕已经更新，可以继续让助手查询任务结果。
- **预览用于检查首屏布局**：动态网页、视频和会议内容的完整效果，以实际播放器显示为准。
- **素材要能正常访问**：已有素材的原文件或预览图失效时，需要补充可用素材。
- **可用功能取决于系统授权和设备支持**：涉及下发、重启或删除时，建议先让助手列出目标和操作内容，核对后再执行。
